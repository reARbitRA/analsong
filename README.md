# AudioIntelligence Pro

A local, rule-based musicological and audio engineering analysis suite built with Gradio, Librosa, NumPy, SciPy, Plotly, and Matplotlib.

## Run

```bash
pip install -r requirements.txt
python app.py
```

Or install the runtime packages directly:

```bash
pip install gradio librosa numpy scipy plotly soundfile pyloudnorm matplotlib numba
```

Then open <http://localhost:7860>.
